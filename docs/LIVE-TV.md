# 全球电视直播

前台 `/live`；后台 `/admin/live`。首次部署需管理员点击「导入全球免费频道」，本次本地测试部署将执行一次导入。固定读取 IPTV-org 的全球 M3U 与频道元数据，不购买接口，不需要 API 密钥。

来源：https://github.com/iptv-org/iptv 和 https://github.com/iptv-org/api 。目录不是全世界所有电视台；仅收录目录中有公开线路、格式兼容且地址校验通过的频道。排除元数据标注的成人频道、内网地址、非 HTTP(S) 协议及非标准端口。特殊请求头线路会标记网页不支持，不伪造请求头或绕过 DRM／订阅／地域控制。

## 中国频道补充线路

`server/src/live-supplements.ts` 保存少量人工实播核对的广电公开地址，不是用户账号、数据库或视频缓存。线索来自 https://github.com/anaer/Meow/blob/main/meow.json ，逐条通过实际中转与网页播放器核对画面和持续播放后收录，不直接整包导入。

2026-10-22 本地 Chrome 测试：河北卫视 960×540、浙江卫视 1920×1080，均连续播放超过一分钟。补充线路在导入时按同一频道 ID 合并、去重并优先使用；每日目录刷新不会覆盖它们，也不会重新开启管理员手动下架的频道。首次导入／下次更新目录会应用补充线路，当前本地部署已单独应用，不需要重置数据库。

CCTV-1、CCTV-13 的新候选尚未通过本次持续实播验证，未作为补充线路添加。排除 HTTP 200 测试图、2023 年停更的旧清单、只能播放二十余秒后卡住的地址，以及拒绝访问／超时／片段 404 的地址。已有目录中的失败频道不会因此被误标为验证通过。可用性只代表本次本地网络测试，不保证其他服务器、地区或未来时段；公开可访问不等于取得商业转播授权。

## 使用

- 按国家／地区、节目类型、名称筛选；24／48／96 条分页，支持页码跳转。一个频道合并最多 30 条线路；缺失地区标为「未标注地区」，不凭频道名猜测。
- 本地导入按用户要求首次默认上架；后台可逐项、本页或按筛选结果批量上下架。订阅更新保留已存在频道的手动选择；新频道默认上架，来源不再提供的频道保留记录但停止展示。
- 可开启每天更新：服务运行时每分钟检查，距上次成功导入满 24 小时后更新；服务关机不运行，重新启动后补检查。下载／解析／保存失败不覆盖旧目录，后台显示错误。它不是后台程序版本升级。
- 播放失败最多自动尝试三条不同线路，还可手动换线／重连。网页不保证支持所有编码、DASH、连续 TS 或特殊平台播放器；检测结果不等于画面声音验证通过。当前不提供 EPG、录制或回看。
- 线路检测已升级为递归检查清单并实际读取一个视频片段；前台可筛选「视频片段可读取／检测失败／尚未检测」。这是检测时间点的网络结果，不等于浏览器解码、音视频或持续可用保证。订阅更换线路后清除旧检测结果。
- HTTP 200 也可能返回「所在地区不可用」或 HTML 错误页；中转会明确识别并拒绝将其伪装成视频。播放器显示地区限制、源站拒绝、超时等安全提示，不显示上游凭证或原始错误页。标准 CCTV 频道失败时提供央视官方网页入口，官方网页同样可能有地区或节目限制。

## 数据、权限与部署

`LiveChannel` 表保存名称、国家、分类、台标 URL、线路和上架状态；`Setting` 的私有 `live:subscription` 保存订阅状态，`AdminLog` 记录导入及上下架。没有下载视频、频道图包或完整视频缓存。原影视 `Source`、会员源分组、账号、积分不改变。

直播复用现有「影视详情与播放」会员权限：登录且具有 `playback` 权限才能读取和播放已上架频道，管理员管理上下架；暂不提供每个会员等级单独指定直播频道的功能。私有订阅状态不经公共设置接口输出。

升级前备份数据库和私有配置，停止旧服务后在新运行目录执行 `npm run build`、`npm run db:push` 再启动，或使用现有部署启动流程（`scripts/start.sh` 会准备结构）。新增表不重置旧数据，禁止使用强制重置／允许数据丢失。SQLite 备份仍用现有一致性备份脚本，包含直播表；MySQL／PostgreSQL 使用原面板／官方备份方案。数据库和生成客户端不得提交 GitHub。

## 直播中转与费用

HLS 从登录保护的 `/api/live/channels/:id/stream/:line` 开始，中转改写子清单、片段和密钥 URI。子请求签名绑定用户和频道、有效期六小时；之后重连即可。每次请求重验上架状态及会员权限。每一跳先验证公网地址、解析 DNS 并固定目标 IP，重定向重新验证；限制响应体、超时和并发，不接受任意无签名 URL 代理。进程重启使旧签名失效，需重新打开频道。

源清单和 JSON 不收费，但**所有直播经服务器中转，会消耗服务器流量**，并发观看需要相应带宽／内存。反向代理保留 `/api/live/`，不要缓存、不要重写为静态首页；可在宝塔／1Panel 的 Nginx 代理中为这个路径关闭缓冲，读超时至少 30 秒。无需 WebSocket 或独立直播端口；Termux／原生 Linux／Docker 使用同一实现。面向持续大并发应使用获授权的 CDN，而不是无上限扩容此内置中转。

公开地址与目录的开源许可不代表频道内容获准再传播；部署者需确认目标地区及实际使用的授权。这里只整理公开目录，不保证频道齐全、全年可用或所有地区可看。
