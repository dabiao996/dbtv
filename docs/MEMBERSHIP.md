# 账号、积分与会员

## 本次提供的功能

- 用户中心 `/membership`：查看积分、会员有效期、当前权限、可兑换套餐和最近100条自己的流水。
- 后台 `/admin/membership`：创建或修改会员等级、设置积分价格和天数、功能及源授权、启用或关闭套餐；赠送或扣减用户积分；查看最近100条全站流水。
- 后台 `/admin/users`：创建账号、禁用普通账号、管理账号额外源授权。余额不允许通过普通账号编辑接口修改。
- 自助注册 `/register`：由后台“允许注册”控制，默认不主动开启。注册固定创建普通账号、0积分，忽略客户端提交的角色、余额或会员等级。

没有在线收款、支付二维码、充值回调或虚构支付订单。积分目前由管理员赠送/调整，再由用户兑换会员；需要微信、支付宝或其他现金支付，必须另行配置合规商户渠道、金额校验、回调验签、对账和退款处理。当前积分不能转账或提现。

## 初次使用

1. 升级前备份数据库，使用项目提供的数据库同步流程增加字段和表。旧账号不重置密码、不发放积分、不自动成为付费会员。
2. 进入“会员与积分”，编辑“普通用户”等级，决定未购买会员的页面和功能权限。
3. 新建会员套餐，填写名称、积分价格和天数，选择权限及数据源；新套餐默认未上架，确认后勾选启用并保存。
4. 在“赠送 / 调整积分”选择账号、填写整数积分和操作原因，确认赠送。负数为扣减，不允许产生负余额。
5. 用户在“会员与积分”选择套餐，在确认窗口明确扣除积分。有效期与余额立即更新，记录可在流水中核对。

默认只创建“普通用户”等级，保留原有功能，源访问沿用账号既有授权。不会擅自发布有价格的会员套餐。管理员不受会员权限限制，也不能通过购买会员获得管理员角色。

## 权限规则

功能权限包括：首页、片库及分类、搜索、影视详情/播放、收藏、观看历史、个性化推荐、评分榜单、弹幕。影片详情接口含真实播放地址，因此归属于“影视详情与播放”权限；仅能浏览片库的用户不能通过详情接口取得播放地址。

权限使用当前有效会员等级；没有有效会员或套餐被关闭时，恢复普通用户权限。服务器每次请求重新检查会话、账号状态、到期时间及套餐权限；前端也检查页面权限，并在导航、重新聚焦和每分钟更新账号状态。修改套餐权限影响该等级的现有会员，关闭套餐也会暂时停止其会员权益，不自动退款，应谨慎操作。

新版编辑器只保留一份「可以观看的源」列表：勾选源组后，成员自动显示勾选并标注组名；也可单独取消其中一个源。未勾选的源不可访问，没有第二份「禁止观看的源」列表。全选与清空统一作用于源和源组，清空后不会因分组仍选中而暗中保留权限。组内分类范围仍会保留，不会因为显示勾选就复制成不受分类限制的单独授权。

从新版编辑器保存等级后，服务器以该等级所选源/源组为准（contentRules.sourceSelection=grade），旧的账号单独源授权、账号额外分组不能扩大这个范围。现有等级在重新保存前保持旧版合并规则，不自动撤销既有权限；部署更新本身不修改真实用户的观看范围。管理员不受这些限制。

勾选源组后取消某个源，服务器在现有 JSON 中记录这一取消项，使它不会被组授权重新放行；重新勾选源或重新选中该组可恢复。这是同一份勾选状态的存储，不是额外的管理界面。自动包含未来源位于「更多源设置」中，默认不打开；全站停用的源始终不可播放。

页面功能权限仅由当前等级决定，源分组不授予页面功能。旧版 User.pageAccess 仅保留兼容存储，不再作为另一条绕过会员等级的授权通道。旧的账号源授权会保留。全站搜索、播放源切换、本地库和推荐服务均使用计算后的可用源集合；遗留搜索入口、原始源配置和直接详情接口也受服务端检查。

## 唯一会员号、搜索和快捷授权

所有账号使用服务器自动生成的 `DTV-` 开头会员号，例如 `DTV-A12B34C56D78`。它有数据库唯一约束、碰撞重试，生成后不可由注册、个人资料或普通账号编辑接口修改。已有账号会自动补号，不重置密码、积分或内部 ID。内部 ID 继续作为唯一主键关联流水与观看记录；会员号供展示、查找和核对，不是密码，也不替代登录凭证。不同独立部署之间不共享会员数据库。

后台赠送积分时，可输入用户名、昵称或完整/部分会员号搜索，服务器分页返回每次20条，不预加载所有账号。必须从结果中选定具体账号才可确认赠送；更改搜索文字会清空原选择，避免误给旧账号。用户管理也支持服务器搜索，单次最多展示200条，需继续输入缩小范围。

权限编辑器支持全选、清空、基础浏览、完整观影，以及按功能小组选中。数据源支持名称筛选、全选所有现有源。后者是当前源列表的固定勾选；“全部启用源”才包含未来新增源。

在「会员与积分 → 源分组」自由新建、命名和选择数据源，例如「高清源」「备用源」，再在账号或会员套餐中一键绑定。也可限定组内源允许的分类/子分类，例如仅开放动作片；未设置分类限制的源开放全部分类。功能按钮不属于源分组。组是动态引用，不是一次性复制；修改、停用分组会同步影响所有绑定对象。分组互不嵌套。其他组、套餐或单独授权可能继续开放同一源，停用一个组不代表全部撤权。分组变动会更新关联套餐版本，阻止旧兑换确认继续使用过时权益信息。

### 示例：普通用户禁止所有源的伦理分类

1. 在「套餐与权限」点选「普通用户」。
2. 选择可看的源/源组，或勾选全部启用源。
3. 在「禁止观看的分类 / 子分类」输入「伦理」，点击「添加分类」再点「保存设置」。默认适用于所有源；指定源和已有分类选择收在展开项中。
4. 要排除整个源，只需在「可以观看的源」里取消它的勾选。相同设置也可用于付费等级。

所有源规则按分类名称匹配，「伦理」覆盖「伦理片」「日本伦理」等含相同分类词的名称；不按片名判断。不同叫法需另加规则，系统不能识别上游错误分类的内容。指定源还可选择真实分类 ID，包含该分类的子分类。源分类读取失败时可手动填写名称；在分类限制下，无法确认分类的内容不放行。旧采集记录若只保存映射后的分类，会查询上游原分类核验；以后采集同时保存 originalCategory，避免映射后丢失依据。

分类与源限制统一过滤搜索结果及其多源选项、片库、分类列表、收藏、历史和详情，并在返回播放地址及写观看记录时检查。已发送到浏览器的第三方直链无法撤回，边界见下文。部分上游分页总数可能仍包括被过滤的资源，不代表有权播放。评分平台的独立影片资料不等于本站可播放资源，实际选源播放仍受上述规则约束。

注册、首次安装、后台创建/重置以及个人修改密码均统一为6–128位，现有密码不自动变更。最低6位是兼容用户需求的设置，管理员仍建议使用更长、更难猜的密码。

## 兑换、续费和账本

- 价格和天数以服务器套餐为准，不采信客户端提交的金额、扣款数或目标账号。
- 用户必须确认看到的套餐版本；后台改动价格/权限后，旧版本兑换请求会被拒绝，须刷新确认。
- 同等级续费从尚未到期的时间向后延长；已到期则从本次兑换时间开始。一天为24小时。
- 有效期内暂不支持跨等级折算和降级购买，避免扣费与剩余天数含义不清。该功能不是自动续费，不会定时扣分。
- 余额上限10亿，每次后台调整绝对值最多100万；套餐价格1–100万积分，期限1–3650天。
- 扣分、余额版本、会员期限和流水在同一数据库事务提交，失败全部回滚。幂等请求标识及唯一约束防止重复请求重复入账；并发使用串行化隔离和版本条件更新，并对事务冲突重试。
- 流水保存用户、操作人、原因、变动、变动后余额、套餐及期限快照。普通用户只能查看自己的账本，后台不能直接编辑/删除账本。为保留审计，用户删除接口停用，改用禁用账号；禁用同时注销会话。

使用普通账号进行真实试用前，先在独立测试数据库验证套餐与权限。测试代码中的金额和账号仅用于临时数据库，不会写入真实用户数据。

## 存储与安全边界

新增 MembershipPlan、PointLedger 表；User 新增 points、walletVersion、membershipPlanId、membershipExpiresAt。随所选 SQLite/MySQL/PostgreSQL 一起存储与备份，不能单独只备份用户表。MySQL 的权限 JSON、套餐说明及流水说明配置了长字段，避免配置被默认短字段截断。外部数据库仍需真实服务集成验收。

凭证仅通过登录会话验证；敏感接口需要管理员，写入还校验请求来源和 JSON。页面/API 不能修改数据库连接。会员和账户响应不允许共享缓存；不向客户端返回密码哈希、会话记录或源接口配置。登录和注册有基础限流，但不包含邮件验证、找回密码、短信、验证码或完整反滥用系统。反向代理需要正确传递 Host；独立前端域名使用服务器 APP_ORIGIN 精确指定受信任来源。HTTPS 部署配置 COOKIE_SECURE=true。

**这不是视频 DRM 或源站鉴权。** 网站只能控制本系统的页面和接口，无法撤回已经发送给浏览器的直链、阻止用户分享外部播放地址，或保证会员到期瞬间中断已建立的视频连接。严格控制视频访问需要自有授权源、短时签名地址和源站校验。不要把第三方影视平台会员权益当作本站会员权益出售；仅为自己有权提供的内容配置会员服务。

管理员修改套餐、赠送或调整积分会记录后台审计。真实收款上线前，还应完善独立支付审计、监控、备份恢复、反向代理和 HTTPS 配置。

## 游客等级

在「会员与积分 → 套餐与权限」选择「游客」，可配置页面功能、可见数据源、源分组和分类限制；关闭「启用游客访问」后需要登录。游客不是付费套餐，无须填写兑换积分或会员天数。默认游客模式保留，管理员应检查是否要缩小可见范围。

这里按源和分类授权，不是按游客等级逐部影片勾选白名单。视频管理中的单片隐藏对全站生效，不仅限制游客。分类与直接访问详情/播放的校验一致；已发出的第三方直链仍受上述安全边界限制。

虚拟展示用户与登录账号、会员等级相互独立，见 [虚拟展示用户](VIRTUAL-UPLOADERS.md)。
